# @w3f/polguard-common

The Common package provides shared types, interfaces, constants, utilities, and telemetry configuration for the entire PolGuard. It ensures type safety, consistency, and shared infrastructure across all packages and services.

This package is used by:
- @w3f/polguard-chain
- @w3f/polguard-matrix
- @w3f/polguard-incident
- @w3f/polguard-config
