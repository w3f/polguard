# @w3f/monitoring-common

The Common package provides shared types, interfaces, constants, utilities, and telemetry configuration for the entire Monitoring Platform. It ensures type safety, consistency, and shared infrastructure across all packages and services.

This package is used by:
- @w3f/monitoring-chain
- @w3f/monitoring-matrix
- @w3f/monitoring-incident
- @w3f/monitoring-config
