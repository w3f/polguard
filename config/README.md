# Configuration Overview

This project includes configuration files for both **development** and **production-like** environments. The configs in the `config/` folder are designed for development and closely resemble a real environment, so they can also be used for integration tests. The `config/examples/` folder contains fully-featured examples showcasing all the available options, ideal for reference or setting up production environments.

## Folder Structure

- **`config/`**: Contains minimal configuration files for **development**. These configurations closely mirror a real environment, making them suitable for both development and potentially some integration testing.
  
- **`config/examples/`**: Contains **example configuration files** that demonstrate all features and options. These are production-like configurations that can be customized for real deployments.
