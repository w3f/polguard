# Development Notes

## Incident Management Service
Currently there is no persistent storage for incidents. Incidents are generated by watcher 
and sent directly to Matrix service through message broker.

### Motivation
- Need persistent storage for audit purposes
- Enable Matrix bot to query incident history
- Support incident acknowledgement functionality
- Track incident lifecycle and status

### Implementation Plan
1. First Phase
   - [x] Create incident storage service with PostgreSQL
   - [ ] Implement basic REST API for incidents CRUD
   - [ ] Add endpoints for incident acknowledgement
   - [ ] Add query endpoint for non-acknowledged incidents

2. Second Phase
   - [ ] Implement incident statistics and reporting
   - [ ] Enable historical analysis

### Migration Checklist
